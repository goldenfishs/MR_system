## 真实 HTTP 流程

以下 8 组检查全部通过：

1. 空数据库通过环境变量创建初始管理员，管理员登录成功，接口返回正式模式。
2. 管理员保存组织、赛季、公告、Hydro 地址、报名开关与截止时间。
3. 管理员创建导师和面试官，两种新账号均能独立登录。
4. 学生注册并提交报名，报名绑定当前会话用户，初始状态为待筛选。
5. 管理员安排面试并分配面试官；面试官读取分配记录并评分；管理员录取后，学生身份更新赛队和方向；学生查询中隐藏内部评分及评语。
6. 导师发布指定赛队／方向的任务；学生提交成果；导师通过并评分；学生可读取审核反馈与提交历史。
7. 成员列表同时包含工作人员与已录取学生。
8. 停止并重启服务，且移除管理员初始化变量后，设置、已有会话、工作人员登录、提交和审核结果仍然保留。

这次验收走完整 HTTP 和数据库路径，没有用前端模拟响应，也没有重复运行单元测试。
