# 财务中心与财务管理

普通登录用户从侧栏「财务中心」提交报销，管理员从「管理工作 → 财务管理」审核与记账。目前统一使用人民币。

## 报销流程

1. 用户填写报销事由、金额、费用发生日期、类别和备注。发票与支付记录分别上传，至少提供一份凭证；一份申请最多 20 个文件，单文件上限沿用网站附件设置（25 MB）。支持图片、PDF、OFD 和其他网站支持的附件格式。
2. 提交后状态为「待审核」。财务查看凭证，可审核通过，或填写原因退回。用户可修改被退回的申请并重新提交，也可撤回待审核或被退回的申请。
3. 审核通过后状态为「待付款」。这时计入待付款金额，尚未计入账本支出。
4. 财务实际转账后，填写付款日期、流水号或付款说明，可附上打款凭证，再选择「确认已付款并入账」。申请变为「已完成」，系统自动生成一笔对应支出。此操作只登记已有付款，不连接银行或发起转账。
5. 已完成记录的金额、付款信息和状态锁定；申请人仍可补交发票。每次操作记录操作者和时间，退回后的修改及补交操作保留原申请版本、原金额和原凭证。

管理员的个人报销也在「财务中心」查看；「财务管理」可以查看全部申请。组管理员不自动拥有财务管理权限。

## 发票识别

管理员在「系统管理 → AI 配置」维护服务商与模型，再在「应用绑定 → 发票识别」选择模型、输入模式并启用。配置步骤见 [AI 配置指南](ai-configuration.md)。未配置或关闭时，用户仍可手动填写报销。

- DeepSeek 服务商使用官方 Base URL；保存密钥后获取模型列表，或手动填写账号可用的准确模型 ID。选择图片识别时，还需确认模型支持图片输入。
- 图片模式要求视觉模型，支持 PNG、JPEG、WebP 和单页 PDF。PDF 由浏览器渲染为图片后发送；识别图片上限为 6 MiB，原始附件上传上限仍为 25 MB。
- PDF 文字模式适合纯文本模型，只接收可提取文字的单页 PDF，最多 30,000 字。扫描 PDF 和照片不适用此模式。
- 多页 PDF 应按发票拆分后再识别；OFD 可以上传并手动填写，暂不支持自动识别。单个文件包含多张发票时也应先拆分。

用户上传后主动点击「识别发票」，页面会显示将凭证发送给哪个模型服务。识别提取金额（优先价税合计）、日期、事项、销售方和发票号码，用户核对后再填入表单。无法识别、币种不明确或不是人民币时，不会把识别金额直接作为人民币报销金额。模型结果只是填写建议，不替代原始凭证、财务审核或实际付款。

API Key 加密保存在服务器，设置接口仅返回是否已保存，不返回密钥内容。更换接口地址时必须重新填写密钥或清除原密钥。服务地址必须为公网 HTTPS 地址，接口不会跟随重定向；识别失败可继续手动填写。系统每个用户同时允许 1 个识别请求、每分钟最多 20 次，全站同时最多 4 个。

## 批量报销

「财务中心 → 批量报销」每批接受 1～20 个发票文件，每个文件生成一条独立申请。可以逐条识别，也可以点击「识别全部发票并填入」顺序识别；批量识别前同样显示模型服务地址。填写或修改各条的事由、金额、类别、费用日期、备注及可选支付记录后，逐条勾选核对确认，再统一提交审核。

整批通过校验才会保存，某一条无效时不会留下部分申请。同批不能重复使用同一发票文件。提交使用用户范围内的批次编号，网络失败后在原表单重试相同内容不会重复建单；修改已成功提交批次的请求内容会被拒绝。成功后，每条申请分别审核、付款、查询和导出。

## 暂无发票与后续补交

发票尚未开具时，可以只上传支付记录提交申请，列表会显示「发票待补」。申请人拿到发票后，在申请详情中选择「补交发票」；待审核、待付款、已退回及已完成的申请都支持补交，已撤回的申请不支持。

补交只追加新发票，不能删除或替换原凭证，也不会改变金额、审核状态、付款记录或账本流水。补交后仍遵守一份申请合计最多 20 个发票与支付记录文件的限制，并保留补交前的版本和操作记录。若需要修改金额或其他已审核内容，应联系财务处理，不能通过补交发票绕过审核。

## 收支账本

「累计入账」「累计支出」「账面余额」根据全部有效流水汇总，不随列表筛选改变。「待付款」单独汇总审核通过但未登记付款的申请。

- 账面余额 = 累计入账 − 累计支出。负数表示已登记支出超过已登记收入。
- 初次启用时，可通过「登记收支 → 转入」，类别填写「期初余额」，登记实际期初资金。
- 经费拨款、赞助等登记为转入；非报销类实际支出可手工登记为转出。
- 报销付款自动入账，不要再手工重复登记。
- 手工流水录错可填写原因作废（页面标为「冲销」）；原记录保留并从汇总中排除。这个操作不会让真实资金退回。报销自动生成的付款流水不能直接作废。

这是单一人民币资金账本，不包含银行余额同步、自动打款或多账户调拨。

## 查询与导出

报销支持状态、申请人/事由/备注、费用日期筛选；账本支持收支方向、类别/往来方/备注及收支日期筛选。点击「筛选」应用条件后再导出。

管理员可勾选多笔申请，导出 CSV 表格或凭证 ZIP；没有勾选时导出当前筛选结果。ZIP 按申请人和申请编号分文件夹，分别保存发票、支付记录、付款凭证及历史版本凭证，并附报销汇总表。一次 ZIP 最多 500 笔、250 MB，超过时请缩小范围分批导出。账本可导出 CSV，包含作废记录及原因，便于复核。

CSV 使用 UTF-8 BOM，便于表格软件识别中文，并对公式起始字符转义。在网站内，财务凭证仅申请人和管理员可访问；用户主动使用发票识别时，凭证图片或提取文字还会发送给页面注明的模型服务。不能将已登记的财务凭证直接复用到公开学习资料、作业等模块。
