# 网页题库管理

系统管理员从侧栏「题库管理」进入；组管理员仍在原有学习页管理其授权组别的题目。

## 同步公开题库

默认仓库是 `goldenfishs/MR_question_bank`，分支 `main`。无需填写 GitHub Token；当前仅支持可匿名读取、符合 v1 清单格式的公开 GitHub 仓库。

1. 选择 C、C++、Python、STM32 等课程。C++ 与 Python 共用算法题会按稳定键去重。
2. 设置新题默认「隐藏，审核后公开」或「直接公开可刷」。此设置不改变既有题目的公开范围。
3. 点击「保存并检查更新」。网站固定本次 commit，下载并校验整个题库，显示新增、更新、已是最新、暂不覆盖。
4. 核对差异后点击「同步到网站」。同步失败不会留下部分导入；同一次预览不可重复应用，重新检查即可再次同步。

此版本为管理员主动点击同步，不会定时无人审核地拉取或发布作业。改动配置后需要重新检查。GitHub 不可达或限流时保留原题库，稍后重试。

## 公开、隐藏和自主添加

下方题目列表可按课程、组别、来源、可见范围或标题筛选，再选中全部筛选结果批量公开/隐藏，也可逐题操作。

- 公开：所有已登录成员可以跨组练习。
- 隐藏（内部题库）：只有有相应权限的管理者可见，可选择加入作业。
- 新增题目：进入原有完整页面编辑器，可自主编写选择、填空、编程及其他已有题型。创建时可选择组别与可见范围。

隐藏源题不改变已经发布的作业快照，不删除历史提交或成绩。编辑已有题目仍遵循原有作答保护规则。

## 冲突和历史保护

同步数据保存在独立 `settings` 行，只向系统管理员返回管理概况。初次接入会尝试识别内置固定 ID 或内容一致的旧题，保留其已有 task ID。内容不同的同名题保留本地版本并报告冲突，不重复创建。

已有本地编辑、作答/判题记录或作业引用的题目不会被远程内容直接覆盖。仓库删题也不会删除网站数据。批量可见性调整只改公开范围，不重算成绩。

当前使用固定 commit 和内容指纹识别变化；尚未提供冲突合并编辑器或自动创建题目新版本。需要保留旧题并采用新内容时，可在网页自主添加新题。

同步仅接受数据：固定 GitHub HTTPS 地址、禁止跳转，限制压缩大小、解压大小、文件数和题数，拒绝不安全路径、符号链接与循环分类，不执行仓库代码。
