# 界面参考与实现

本次视觉调整以用户指定的[华南虎面试系统介绍演示](https://www.bilibili.com/video/BV1DC4y1f7Fh/)为参考，并核对了 [HR_Frontend](https://github.com/scutrobotlab/HR_Frontend) 的公开界面结构。

## 采用的视觉特征

- 青色经蓝色过渡到紫色的固定顶栏；招新状态和任务类型直接使用白字标签、黄色选中线切换。
- 白色分组侧栏，技术方向可直接筛选名单；手机端折叠为抽屉。
- 侧栏头部与主工具栏同高（64 px），M 标识配合「QUT机器人战队」「沧溟 / MOVE」两行信息，导航图标与文字保持 18 px 间距。
- 以人物名单、时间和状态为主的招新工作台；右侧绿色新增趋势、玫红志愿分布使用真实可见报名数据。
- 6 px 卡片、4 px 按钮、圆形头像、常规字重和较紧凑的 Material 表单。
- 工作台采用彩色功能图标与任务、面试列表；登录页使用居中表单、同一战队双赛事说明和可配置品牌。
- 技术组使用「首页、知识库、作业、考试」顶栏，电控、视觉算法与硬件追加「题库」。题库参考 Hydro 的紧凑列表组织方式，提供真实搜索、标签、难度和尝试／通过统计。
- 侧栏统一为团队报名、学习与任务、讨论区、荣誉中心和个人中心；个人中心整合资料、个人档案与附件。管理员页面使用相同导航与分组，并提供发布、评阅、公开问答和按人发放证书操作。

统计图的颜色只用于表达数据。报名趋势按本地日期计算近七天，志愿统计按第一志愿分组；候选人状态和方向筛选不会改变统计口径，招募空间筛选会改变统计范围。学生仍只读取本人的报名、允许访问的任务和本人提交，未开考的题目正文及附件由服务端隐藏。

默认品牌为青岛理工大学机器人战队，沧溟 / MOVE 是同一支队伍的双语名称，同时参加 RoboCon 和 RoboMaster。默认 M 标志由用户提供的透明原图制作；管理员可替换名称、赛事及标志，也可直接上传 PNG／JPEG。界面使用独立编写的 Vue 和 CSS，没有复制参考项目源码或视频素材。

知识库、讨论区、荣誉中心和个人中心均连接实际 API；加载失败、空数据、未配置邮件或判题服务会显示对应状态，界面不生成虚构成功结果。
