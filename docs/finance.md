# 财务中心与财务管理

普通登录用户从侧栏「财务中心」提交报销，管理员从「管理工作 → 财务管理」审核与记账。目前统一使用人民币。

## 报销流程

1. 用户填写报销事由、金额、费用发生日期、类别和备注。发票与支付记录分别上传，至少提供一份凭证；一份申请最多 20 个文件，单文件上限沿用网站附件设置（25 MB）。支持图片、PDF、OFD 和其他网站支持的附件格式。
2. 提交后状态为「待审核」。财务查看凭证，可审核通过，或填写原因退回。用户可修改被退回的申请并重新提交，也可撤回待审核或被退回的申请。
3. 审核通过后状态为「待付款」。这时计入待付款金额，尚未计入账本支出。
4. 财务实际转账后，填写付款日期、流水号或付款说明，可附上打款凭证，再选择「确认已付款并入账」。申请变为「已完成」，系统自动生成一笔对应支出。此操作只登记已有付款，不连接银行或发起转账。
5. 已完成记录锁定。每次操作记录操作者和时间，退回后的修改保留原申请版本、原金额和原凭证。

管理员的个人报销也在「财务中心」查看；「财务管理」可以查看全部申请。组管理员不自动拥有财务管理权限。

## 收支账本

「累计入账」「累计支出」「账面余额」根据全部有效流水汇总，不随列表筛选改变。「待付款」单独汇总审核通过但未登记付款的申请。

- 账面余额 = 累计入账 − 累计支出。负数表示已登记支出超过已登记收入。
- 初次启用时，可通过「登记收支 → 转入」，类别填写「期初余额」，登记实际期初资金。
- 经费拨款、赞助等登记为转入；非报销类实际支出可手工登记为转出。
- 报销付款自动入账，不要再手工重复登记。
- 手工流水录错可填写原因作废（页面标为「冲销」）；原记录保留并从汇总中排除。这个操作不会让真实资金退回。报销自动生成的付款流水不能直接作废。

这是单一人民币资金账本，不包含银行余额同步、自动打款或多账户调拨。

## 查询与导出

报销支持状态、申请人/事由/备注、费用日期筛选；账本支持收支方向、类别/往来方/备注及收支日期筛选。点击「筛选」应用条件后再导出。

管理员可勾选多笔申请，导出 CSV 表格或凭证 ZIP；没有勾选时导出当前筛选结果。ZIP 按申请人和申请编号分文件夹，分别保存发票、支付记录、付款凭证及历史版本凭证，并附报销汇总表。一次 ZIP 最多 500 笔、250 MB，超过时请缩小范围分批导出。账本可导出 CSV，包含作废记录及原因，便于复核。

CSV 使用 UTF-8 BOM，便于表格软件识别中文，并对公式起始字符转义。财务凭证仅申请人和管理员可访问；不能将已登记的财务凭证直接复用到公开学习资料、作业等模块。
