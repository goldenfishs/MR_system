# 团队工作流程

## 战队与品牌

青岛理工大学机器人战队是一支队伍，沧溟 / MOVE 是它的中文与英文名称，同时参加 RoboCon 和 RoboMaster。成员、报名、培养与荣誉统一管理，不按两个名称拆分队伍。

管理员在「空间设置」修改学校／战队全称、平台展示名称、中英文队名与参赛赛事。登录页和侧栏共用标志，可上传 2 MiB 以内的 PNG／JPEG，或填写公开静态路径／图片 URL。上传按钮会立即替换标志，其他文字修改需点击「保存设置」。新标志生效后旧标志的公开上传地址失效，个人照片与证书不会因此公开。

## 注册与入队

1. 学员仅填写邮箱、密码和确认密码，通过邮箱验证码注册；邮箱即登录账号，验证码有效期 10 分钟。注册成功自动登录，资料未完整时会提示前往个人中心。
2. 管理员在「团队报名」分别发布机械组、电控组、硬件组、视觉算法组、运营组五个单方向团队，均属于沧溟（MOVE）机器人战队，同时参加 RoboCon 与 RoboMaster。每组可设置独立截止时间或长期开放。
3. 学员先在「个人中心 → 个人资料」填写姓名、性别、学校、专业、班级、学号、联系电话，并上传 JPEG／PNG 本人证件照（不超过 2 MiB）；兴趣爱好和个人头像选填。头像用于账号展示，证件照用于报名审核，两者分别保存。再选择开放空间与方向、上传 PDF 简历提交报名。资料只需填写一次，未完整不能提交报名。
4. 同一用户可以同时报名多个组，每组独立审核。管理员查看资料和简历、填写意见并通过后，成员获得该团队与组别的作业及考试提交资格。通过任一组即可浏览所有组学习内容；其他组未录取时仅供参考。历史团队与审核记录保留，不会因品牌修改而丢失。

侧栏始终展示五个组别，已报名且待审或录取有效的组显示 🌟；被拒绝或对应培养淘汰后去掉该组星标。未获学习资格时点击组别会引导前往报名。

## 各组阶段考核

「新生考核」同时展示每个已录取团队与组别的最新培养进度，可按组筛选，并选择显示历史周期。各组独立经历基础学习、阶段考核、最终考核，也可由管理员配置自己的阶段方案。

管理员或获本组考核权限的组管理员逐阶段确认通过或淘汰；淘汰仅关闭当前团队与组别的提交资格，其他组的报名、作业、考试和培养不受影响。重新参加已淘汰的组须由有考核权限者明确重新录取。最终考核通过可确认梯队或正式队员身份，保留已有更高身份；其他尚未结束的组别培养仍继续考核。正式或梯队队员新加入另一个组时，同样需要参加该组的培养与考核。

## 技术组首页与知识库

在「学习与任务」选择技术方向后，顶栏提供「首页、知识库、作业、考试」。机械、电控、视觉算法与硬件另有「题库」；机械题库提供自动判分的选择／填空题和下载自练的图纸题，电控、视觉算法与硬件题库提供编程练习。运营保留文件／作品培养，不提供题库。机械与运营不提供代码考核选项。

组首页汇总当前可访问的作业、考试排期与完成情况。有效录取组的任务按发布要求标为本组必做或选做，其他组的任务标为参考；考试开始前也可查看本组排期，开始后才能提交。管理员／导师在知识库发布资料标题、说明与附件，支持普通文件、PDF 和视频。文件可下载；PDF 可预览，视频可使用上传文件或外部链接。PDF 类型必须关联 PDF 文件。资料按技术方向筛选，个人照片、简历与证书不能作为知识库资料公开。

## 作业与评阅

管理员／导师在「学习与任务」发布作业，指定已发布团队和方向，填写文字要求、附件及评分上限。

| 方向 | 常用提交形式 |
| --- | --- |
| 机械 | 说明文档、CAD／STEP 文件、工程压缩包 |
| 电控 | 单个源码文件、完整固件工程压缩包、编程题 |
| 硬件 | PCB、KiCad、Gerber、电路设计与说明文件 |
| 视觉算法 | 源码、Notebook、算法工程压缩包、测试报告 |
| 运营 | 图片、设计稿、文档及素材压缩包 |

上传文件可在各业务表单重复选择，也可在「个人中心 → 我的附件」统一查询；侧栏不再提供独立文件中心。文件单个不超过 25 MiB，每人当前限额 250 MiB。一个任务或提交最多关联 20 个附件。尚未提供文件删除及回收站；压缩包不在应用服务器解压，工程文件只托管和下载。JPEG／PNG 会重新编码以移除附加内容，其余格式下载查看。

每次作业提交创建新版本。管理员／导师下载成果、填写评分和反馈，可通过或退回修改；只能审核最新版本，旧版本保留。指定团队的任务要求本人拥有该团队与方向的有效录取关系，不因加入其他组或已晋升正式／梯队队员而自动分配。历史任务按有效成员方向兼容。

## 定时考试与题库

管理员／导师在本组「考试」安排文件考试或代码考试，必须设置开始和截止时间。开始前，成员只能查看排期与分值，题目正文、要求附件及测试用例由服务端隐藏；开始后自动开放，截止后不能评测或提交。机械与运营考试采用文件／作品提交，电控、视觉算法与硬件还可使用单文件代码评测。

各组日常训练与考核统一在「作业」管理。机械、电控、视觉算法与硬件的「题库」支持名称／标签搜索、知识标签、难度筛选和排序。题库不是多题试卷，浏览与提交资格沿用所属团队及组别规则。

管理员或获机械组任务权限的组管理员可在「题库」发布单选题、多选题、填空题和图纸练习。选择／填空题须设置标准答案，学员在线作答后由系统自动判分并显示答案与解析，无需配置编译服务。每题全部答对获得满分，否则为 0 分，可再次练习；多选不区分选择顺序，填空按空位顺序精确匹配、忽略首尾空白但区分大小写。题库列表显示实际作答次数及答对次数，曾答对的题目显示通过标记。在线作答须具备本题所属团队及机械组的有效录取资格，并在题目开放时间内进行。

图纸题用于下载后自主练习。管理员至少上传一份题目图纸，也可附参考答案说明或参考答案文件；参考答案不是必填项。学员可在题目开放后下载图纸和已提供的参考资料，自行完成练习，无需上传作品或等待评分，系统不记录图纸练习的答题成绩。

电控、视觉算法与硬件的题库用于编程练习，AC／尝试统计来自实际完成的代码评测，不包含排队、运行中或服务错误记录。

部署者配置 `JUDGE_URL` 和可选 `JUDGE_TOKEN`，指向自行部署的 **Judge0 CE 兼容服务**。应用通过 `/languages`、异步 `/submissions` 及结果查询接口通信，密钥使用 `X-Auth-Token` 请求头。该服务必须运行在独立隔离环境，保持沙箱及网络隔离，使用仍受维护的版本；Compose 不自动部署它。应用不允许设置自定义编译命令。

老师选择「代码」提交，启用自动评测，选择服务支持的语言、输入输出用例和单例时限。发布电控、视觉算法或硬件的编程题库题目必须启用自动评测。学员上传 UTF-8 单文件源码（最多 64 KiB），点击编译运行，等待结果后提交该源码与评测记录。整个项目压缩包使用普通文件任务人工评阅。

每题最多 10 个用例、单例 CPU 0.1–5 秒、内存 256 MiB，并要求判题服务关闭被测程序网络。应用同时最多处理 2 份评测，每人每分钟最多 5 次。隐藏用例不会向学员返回输入、预期答案或执行输出。自动分数不替代最终人工评分。

没有配置服务时，普通代码文件任务仍可用；已启用自动评测的任务必须完成评测后才能提交。服务错误和重启中断会显示失败，不伪造通过结果。本地验证使用协议桩，真实编译服务与隔离部署仍需部署者配置并验收。当前不含多题试卷、监考及工程依赖环境自动构建。Hydro 仍是独立入口。

## 讨论区

学员可在「讨论区」向机械、电控、视觉算法、硬件或运营提问。新问题只对提问者、管理员和导师可见；面试官不能读取他人的私有问题。提问者与工作人员可以回复，管理员／导师在已有回复后标记「已解答」。

只有管理员能将已解答的重要问答公开给已登录用户。公开后问答只读，若需继续回复，管理员先取消公开。公开操作会展示提问内容和作者姓名，因此应先确认内容适合共享。

## 荣誉中心与个人中心

管理员在「荣誉中心」选择具体用户，填写标题、类型（证书／奖励／通知）、说明和日期，附上面试通过证书、奖状等文件。用户查询自己的材料，PNG／JPEG 可直接预览并放大，其他文件下载查看。管理员可查看全部，普通成员只能查看本人荣誉；附件不会因发放而变成公开资源。

「个人中心」整合个人资料、个人档案与我的附件。这里的个人档案只显示当前用户收到的荣誉，与「荣誉中心」使用同一记录来源。

## 批量邮件

在「批量邮件」选择系统用户、写主题与纯文本正文，保存草稿并预览。点击发送后分别投递，每封邮件只包含一个收件人，不暴露其他邮箱。当前单批最多 200 人，同时最多发送两批。

「已送出」表示 SMTP 服务接受邮件，不保证最终进入收件箱。明确失败项可单独批量重试，已成功项不会重发；发送确认丢失或进程重启导致状态不确定时标记「待核实」，需管理员查看邮件服务记录。邮件不支持附件，可在正文提示用户登录荣誉中心查看已发放材料。SMTP 配置见 [邮箱注册配置](email-registration.md)。真实发信服务尚需部署者配置，本地 Mailpit 验证不代表真实投递成功。

## 数据与运维

数据库升级保留旧账号和旧面试记录，新团队关系单独保存。生产部署使用一个应用实例，并一起备份数据库和上传目录。注册资料、简历和个人档案不能提交到公开 Git 仓库。当前导师拥有全平台作业管理权限，尚未细分为每团队导师授权。
