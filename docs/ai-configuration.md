# AI 配置与业务接入

从「系统管理 → AI 配置」进入独立管理页。配置按服务商、模型、应用分开保存：同一服务商的地址与密钥只填写一次，多种模型可以复用；具体功能选择自己的模型，不需要重复维护连接。

## 管理员操作

1. 新增服务商，填写显示名称、API Base URL 和 API Key。支持兼容 OpenAI Chat Completions 的服务，如 DeepSeek 或兼容网关。Base URL 应为服务商提供的 HTTPS API 根地址（可能包含 `/v1`），不要填写网页聊天地址。
2. 保存连接后获取模型列表，选择需要的模型加入；服务商没有列表接口时，可以手动填写准确的模型 ID。获取列表不会自动启用或导入全部模型。
3. 逐个设置模型名称、启用状态与图片能力。模型列表未声明图片能力时需要管理员确认，不能仅凭名称猜测。连接测试只验证一次简短文本调用，不能证明图片能力或发票识别准确率。
4. 在「应用绑定」中为发票识别选择模型及输入模式。图片模式要求模型标记支持图片；文字模式用于可提取文字的 PDF。保存并启用后，财务中心的识别入口即可使用。
5. 新增自定义应用配置可提前指定模型和提示词。这是供开发者接入的配置档案，创建后不会自动生成聊天窗口、业务功能或公开 API。

页面修改统一保存；测试和获取模型列表使用已保存配置。两位管理员同时修改时，较旧版本会收到冲突提示，需核对最新配置后再保存，避免覆盖他人修改。

## 现有设置兼容

已有发票识别连接会显示为一个服务商、一个模型及「发票识别」应用，原密钥不回显、不需要重新复制。未填完的旧配置也会保留为待完善服务商。旧自定义完成接口路径会保留，明确修改服务商地址后改用标准路径。首次保存统一配置后，发票识别由应用绑定管理；旧设置入口跳转到新页面。关闭服务商、模型或应用，会停止相关业务的 AI 调用，普通手工报销不受影响。

业务模块只按稳定的应用 ID 选择配置，发票识别 ID 为 `finance-invoice`。变更绑定即更换该业务使用的模型；删除模型或服务商前需先解除引用或在同次保存中完成重新绑定。

## 扩展方式

新业务仍需编写自己的权限检查、输入整理、提示词、输出校验与限流，再通过 `callAIApplication(ctx, applicationID, userContent, maxTokens)` 解析应用绑定并发送请求。更复杂的业务可使用 `resolveAIApplication`、`aiProviderClient` 和 `requestAICompletion` 组合输入与固定输出约束；发票识别沿用自己的结构校验并共用底层调用。上传文件与业务数据不能因为配置了模型就自动开放给模型服务。自定义提示词不应替代业务侧固定的输出结构及数据校验。

当前实现文本及图片消息的 OpenAI-compatible 调用、模型列表与连接测试。语音、Embedding、Rerank、原生 Anthropic/Gemini 协议、工具执行与 Agent 工作流不在此版本内；需要时可增加适配器和业务应用，沿用服务商和模型引用关系。

## 密钥与外部调用

只有系统管理员可以查看和修改连接配置。密钥加密保存，接口仅返回是否已配置；留空保留旧密钥。更换服务商地址时需要重新提供密钥或清除旧密钥，避免凭证被转发到新地址。外部调用限制为公网 HTTPS，验证 DNS 并固定连接地址，禁止重定向和代理绕过。

发票识别仍由用户主动触发，页面展示目标服务商；识别结果需要人工核对。连接测试使用固定的合成文本，不发送用户发票、报名、成绩或其他业务记录。

## 设计参考

参考 AstrBot 的结构与交互，MR 独立实现配置和调用逻辑：

- [ProviderManager](https://github.com/AstrBotDevs/AstrBot/blob/master/astrbot/core/provider/manager.py)：`provider_sources` 保存共享连接，模型配置通过 `provider_source_id` 引用，并按 ID 解析实例。
- [Provider 抽象接口](https://github.com/AstrBotDevs/AstrBot/blob/master/astrbot/core/provider/provider.py)：统一模型列表与对话调用接口，并区分输入能力。
- [OpenAI 兼容适配器](https://github.com/AstrBotDevs/AstrBot/blob/master/astrbot/core/provider/sources/openai_source.py)：通过模型列表接口发现模型，通过 Chat Completions 调用模型。

以上是结构参考，不包含 AstrBot 插件执行环境或源代码移植。
