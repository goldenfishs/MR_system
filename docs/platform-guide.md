# 团队工作流程

## 注册与入队

1. 学员填写邮箱、密码，上传 JPEG／PNG 照片（不超过 2 MiB），填写姓名、性别、学校、专业、班级、学号、联系电话；兴趣爱好选填。邮箱验证码有效期 10 分钟。
2. 管理员在「团队招募」发布团队，选择赛事及机械、电控、视觉算法、硬件、运营方向，设置截止时间或长期开放。
3. 学员选择团队与方向，上传 PDF 简历。个人资料只需填写一次；已有账号先在「个人资料」补全。
4. 管理员查看报名资料和简历，填写意见并通过。成员可加入多个团队，每个团队单独保存方向与审核结果。

## 作业与评阅

管理员／导师在「学习与任务」发布作业，指定已发布团队和方向，填写文字要求、附件及评分上限。

| 方向 | 常用提交形式 |
| --- | --- |
| 机械 | 说明文档、CAD／STEP 文件、工程压缩包 |
| 电控 | 单个源码文件、完整固件工程压缩包、编程题 |
| 硬件 | PCB、KiCad、Gerber、电路设计与说明文件 |
| 视觉算法 | 源码、Notebook、算法工程压缩包、测试报告 |
| 运营 | 图片、设计稿、文档及素材压缩包 |

文件中心支持上传后重复选择；文件单个不超过 25 MiB，每人当前限额 250 MiB。一个任务或提交最多关联 20 个附件。尚未提供删除及回收站；压缩包不在应用服务器解压，工程文件只托管和下载。JPEG／PNG 会重新编码以移除附加内容，其余格式下载查看。

每次作业提交创建新版本。管理员／导师下载成果、填写评分和反馈，可通过或退回修改；只能审核最新版本，旧版本保留。公开团队任务只允许已入队且方向匹配的学员提交，历史任务沿用历史录取关系。

## 代码练习与编程考试

部署者配置 `JUDGE_URL` 和可选 `JUDGE_TOKEN`，指向自行部署的 **Judge0 CE 兼容服务**。应用通过 `/languages`、异步 `/submissions` 及结果查询接口通信，密钥使用 `X-Auth-Token` 请求头。该服务必须运行在独立隔离环境，保持沙箱及网络隔离，使用仍受维护的版本；Compose 不自动部署它。应用不允许设置自定义编译命令。

老师选择「代码」提交，启用自动评测，选择服务支持的语言、输入输出用例和单例时限。编程考试还需开始、截止时间。学员上传 UTF-8 单文件源码（最多 64 KiB），点击编译运行，等待结果后提交该源码与评测记录。整个项目压缩包使用普通文件任务人工评阅。

每题最多 10 个用例、单例 CPU 0.1–5 秒、内存 256 MiB，并要求判题服务关闭被测程序网络。应用同时最多处理 2 份评测，每人每分钟最多 5 次。隐藏用例不会向学员返回输入、预期答案或执行输出。自动分数不替代最终人工评分。

没有配置服务时，普通代码文件任务仍可用；已启用自动评测的任务必须完成评测后才能提交。服务错误和重启中断会显示失败，不伪造通过结果。当前不含多题试卷、监考及工程依赖环境自动构建。Hydro 仍是独立入口。

## 奖状与个人档案

管理员在「档案发放」选择具体用户，填写标题、类型（证书／奖励／通知）、说明和日期，附上文件。用户在「我的档案」查询自己的材料。管理员可查看全部，普通成员只能查看本人档案；附件不会因发放而变成公开资源。

## 批量邮件

在「批量邮件」选择系统用户、写主题与纯文本正文，保存草稿并预览。点击发送后分别投递，每封邮件只包含一个收件人，不暴露其他邮箱。当前单批最多 200 人，同时最多发送两批。

「已送出」表示 SMTP 服务接受邮件，不保证最终进入收件箱。明确失败项可单独批量重试，已成功项不会重发；发送确认丢失或进程重启导致状态不确定时标记「待核实」，需管理员查看邮件服务记录。邮件不支持附件，可在正文提示用户登录查看已发放的个人档案。SMTP 配置见 [邮箱注册配置](email-registration.md)。

## 数据与运维

数据库升级保留旧账号和旧面试记录，新团队关系单独保存。生产部署使用一个应用实例，并一起备份数据库和上传目录。注册资料、简历和个人档案不能提交到公开 Git 仓库。当前导师拥有全平台作业管理权限，尚未细分为每团队导师授权。
