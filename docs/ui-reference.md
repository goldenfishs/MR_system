# 界面参考与实现

本次视觉调整以用户指定的[华南虎面试系统介绍演示](https://www.bilibili.com/video/BV1DC4y1f7Fh/)为参考，并核对了 [HR_Frontend](https://github.com/scutrobotlab/HR_Frontend) 的公开界面结构。

## 采用的视觉特征

- 青色经蓝色过渡到紫色的固定顶栏；招新状态和任务类型直接使用白字标签、黄色选中线切换。
- 白色分组侧栏，技术方向可直接筛选名单；手机端折叠为抽屉。
- 以人物名单、时间和状态为主的招新工作台；右侧绿色新增趋势、玫红志愿分布使用真实可见报名数据。
- 6 px 卡片、4 px 按钮、圆形头像、常规字重和较紧凑的 Material 表单。
- 工作台采用彩色功能图标与任务、面试列表；登录页改为居中表单。

统计图的颜色只用于表达数据。报名趋势按本地日期计算近七天，志愿统计按第一志愿分组；候选人状态和方向筛选不会改变统计口径，赛队筛选会改变统计范围。学生仍只读取本人的报名、允许访问的任务和本人提交。

保留竞跃自己的名称与标识。实现为独立编写的 Vue、CSS 和 SVG，没有复制参考项目源码、品牌标识或视频素材；也没有为还未实现的功能添加入口。

## 本次验收

- TypeScript 检查和生产构建通过。
- 浏览器验证顶部状态筛选、技术组切换、任务类别、成果历史与评分反馈、登录注册切换、学员和管理员登录、候选人详情。
- 检查桌面两列名单与统计布局、手机工作台和候选人名单；手机视口未出现整页横向溢出。
- 本次调整保留原有 API 和业务权限，没有改动后端。
